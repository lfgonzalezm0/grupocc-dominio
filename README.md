# grupocc.org sin www

El dominio raíz se administra en Microsoft 365, que no permite apuntarlo a Railway. Esta página sirve el archivo de asociación que Android exige en el dominio de las passkeys y lleva todo lo demás a `www.grupocc.org`.

`.well-known/assetlinks.json` es copia del de GCC World: al cambiar una firma, cambiar los dos.
